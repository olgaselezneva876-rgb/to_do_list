# День за днём

Личный планировщик на русском языке. Добавляй задачи на любую дату, выбирай приоритет, редактируй и отмечай выполненное. Кольцо дня и семь колец недели пересчитываются автоматически.

## Запуск

Самый простой способ: открой `index.html` двойным щелчком в Chrome или Edge. Установка зависимостей не нужна.

Для постоянного локального адреса открой PowerShell в папке `project/to_do_list` и выполни:

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

Открой <http://127.0.0.1:8000>. Остановка сервера — `Ctrl+C` в терминале. Python нужен только для этого способа запуска.

## Использование

- Выбирай день через календарь, стрелки или кнопку «Сегодня».
- Введи название, выбери «Срочно», «Второстепенно» или «Можно сделать потом» и нажми «Добавить» (или Enter).
- Галочка отмечает выполнение; повторное нажатие возвращает задачу в работу.
- Карандаш открывает редактирование, крестик удаляет задачу.
- Недельный блок показывает семь дней, заканчивающихся выбранной датой. Нажатие на день открывает его задачи.
- Все задачи равнозначны при расчёте процента. Пустой день отображается как «Нет задач».

## Хранение

Задачи сохраняются автоматически в localStorage браузера. Используй один браузер и один адрес запуска: прямое открытие файла и адрес HTTP имеют разные хранилища; разные порты также дают отдельные хранилища. Для файлов поведение хранения зависит от браузера, поэтому для постоянного использования предпочтителен локальный сервер.

Данные не отправляются в интернет и не синхронизируются между устройствами. Очистка данных браузера удаляет задачи; приватный режим не подходит для постоянного хранения. При ошибке сохранения появится сообщение. Повреждённые данные приложение не перезаписывает. Открытые вкладки на одном адресе получают обновления; при обнаружении конфликта несохранённых изменений приложение сообщает о нём.

## Проверки

Из этой папки, при установленном Node.js:

```powershell
node --test core.test.cjs
node browser.test.cjs
```

Первая команда проверяет логику дат, задач, прогресса и формата хранения. Вторая запускает установленный Chrome без окна, проверяет реальные действия интерфейса, сохранение и ошибки, затем сохраняет `preview-desktop.png` и `preview-mobile.png`. Для другого пути Chrome задай переменную `CHROME_PATH`. Тест использует отдельный профиль внутри `.browser-test-profile`, не затрагивая личные задачи.

Приложение состоит из `index.html`, `styles.css`, `core.js` и `app.js`. Остальные файлы нужны для документации и проверки.
